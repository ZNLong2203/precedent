      What is in the graph?

      (:Decision) a record · (:Clause) one numbered point of it · (:CodePath) a file it mentions.

      -[:SUPERSEDES | REVERSES | WITHDRAWS | AMENDS]-> how a later decision treats an earlier one, with the clauses it names, the quoted evidence sentence, and whether it took effective hold. -[:CITES]-> is a plain citation. standing is derived: in_force, partial or out.

      Why this exists

      A decision record says what a team decided, when and why. Nobody edits it afterwards. So when the team changes its mind, the change is a new record containing a sentence like §4 is superseded, and the old one still says Status: Accepted.

      A person skimming the log, or an AI agent searching it, lands on the old record and acts on rules nobody follows any more. Precedent reads those sentences, links the records in a graph, and works out clause by clause what still holds.

      How it decides

      1. Read. Find the sentences where one decision supersedes, reverses, withdraws or amends another, and which numbered clauses they name. Each sentence is kept as evidence.
      2. Link. Store them as typed edges in a Relate graph: (ADR-0229)-[:SUPERSEDES {clauses: [1, 4, 5, 7, 10]}]->(ADR-0116).
      3. Judge. A clause is overruled if a decision that itself still stands overrules it. If the overruler was overruled in turn, the original comes back.
